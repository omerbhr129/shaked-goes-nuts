# SHAKED GOES NUTS 🥜

משחק מסיבת רווקים: בורסת הימורים, משימות סודיות, הצבעות ושאלות, עם מסך טלוויזיה, טלפון לכל משתתף ומסך מנחה. נבנה למסיבת הרווקים של איתי (אוקטובר 2026), והקוד פתוח לכל מי שרוצה להריץ עותק למסיבה משלו.

## שלושה מסכים

| כתובת | למי |
|---|---|
| `/` | הטלפון של כל משתתף: בוחרים שם, מהמרים, מצביעים, משימות סודיות, שולחים תמונות וסרטונים למסך |
| `/tv` | הטלוויזיה (מחשב מחובר למסך, בספארי או כרום). לוחצים פעם אחת "הפעלת סאונד", ו־F למסך מלא |
| `/admin#key=<קוד המנחה>` | מסך המנחה: גלגל הבלגן, אתגרים, שיפוט "תפסתי", לוח סאונדים, מה מוצג בטלוויזיה |

## הרצה מקומית

צריך Node 22.

```bash
npm install
cp .dev.vars.example .dev.vars   # ולשנות את ADMIN_KEY לקוד שתבחרו
npm run dev                      # http://localhost:5173
```

מסך המנחה המקומי: `http://localhost:5173/admin#key=<הקוד מ־.dev.vars>`

## עותק משלכם באינטרנט

המשחק רץ על Cloudflare Workers עם Durable Object אחד, והתוכנית החינמית מספיקה. אין בהגדרות שום חשבון קבוע, אז כל אחד פורס לחשבון שלו:

```bash
npx wrangler login
npx wrangler secret put ADMIN_KEY        # קוד המנחה
npm run deploy                           # בונה ומעלה
```

**הקריין (לא חובה):** `npx wrangler secret put OPENAI_API_KEY` עם מפתח משלכם. בלי מפתח המשחק עובד רגיל, רק בלי קול. משפטים שכבר הוקלטו ממשיכים להתנגן.

## עדכון אוטומטי מגיטהאב

כל שינוי שנכנס ל־`main` עובר בדיקת טיפוסים ובנייה, ואם במאגר מוגדרים שני סודות הוא גם עולה לאתר לבד:

- `CLOUDFLARE_API_TOKEN`: אסימון מלוח הבקרה של Cloudflare (My Profile ← API Tokens ← התבנית "Edit Cloudflare Workers").
- `CLOUDFLARE_ACCOUNT_ID`: מזהה החשבון (מופיע בלוח הבקרה, או ב־`npx wrangler whoami`).

מגדירים אותם במאגר בגיטהאב: Settings ← Secrets and variables ← Actions. עותקים בלי הסודות פשוט מדלגים על העלאה.

## בדיקה מלאה

```bash
SKIP_TTS=1 node scripts/sim.mjs http://localhost:5173 <קוד המנחה>
```

מריצה מאות בדיקות על כל המשחק: הימורים, משימות, הצבעות, הגמר, קלפי החתן, תחרות תמונות ועוד.

⚠️ **הבדיקה מאפסת את המשחק ומנתקת את כולם.** אף פעם לא להריץ אותה על האתר החי בזמן מסיבה. `SKIP_TTS=1` מדלג על הקריין, כדי שהבדיקה לא תפנה ל־OpenAI.

## אחרי המסיבה

התמונות והסרטונים שנשלחו נשמרים רק באתר. לפני שמורידים אותו:

```bash
node scripts/export.mjs https://<הכתובת שלכם> <קוד המנחה> "<תיקייה>"
```

נוצרת תיקייה עם כל התמונות והסרטונים, כל קובץ בשם של מי ששלח ומתי. יש בה גם קובץ טקסט עם הדירוג הסופי וההודעות שעלו למסך, וגיבוי מלא של נתוני המשחק. הודעות אנונימיות נשארות אנונימיות.

אחר כך `npx wrangler delete` מוריד את האתר. זה מוחק גם את כל הנתונים שלו, ואין דרך לשחזר.

## להתאים למסיבה אחרת

- **שחקנים, אתגרים, שאלות, הצבעות, הימורי לילה ומשימות:** `src/worker/seed.ts`. אחרי שינוי ופריסה, הכפתור "טעינת התוכן ההתחלתי" במסך המנחה (לשונית השחקנים) טוען אותו. זהירות: זה מוחק את המשחק הנוכחי.
- **תמונות פרופיל:** `public/photos/<מזהה השחקן>.jpg`. בזמן אמת כל משתתף יכול להחליף תמונה ושם מהטלפון.
- **תמונות לרגעים הגדולים** (מלך, שוט, אלוף): `public/photos/ai/...` לפי מזהה השחקן. בלי תמונה, מוצגת תמונת הפרופיל.
- **חנות המתנות, משחקי הדו־קרב, לוח הסאונדים ושקפי "איך משחקים":** `src/shared/catalog.ts`.
- **התמונה שמופיעה כששולחים את הקישור** (למשל בוואטסאפ): `public/og.jpg`. יש אפליקציות שמציגות אותה רק עם כתובת מלאה, אז כדאי לכתוב ב־`index.html` את הכתובת של האתר שלכם במקום `/og.jpg`.
- **הרבה מהתוכן אפשר לערוך גם ממסך המנחה בזמן אמת,** בלי לשנות קוד.

## מבנה

```
src/worker/   השרת: כל חוקי המשחק (logic.ts), מה כל מסך רואה (views.ts), חדר המשחק, העלאות וקריין (room.ts)
src/shared/   טיפוסים וקטלוגים משותפים
src/client/   player/ הטלפון · tv/ הטלוויזיה · admin/ המנחה
scripts/      sim.mjs, הבדיקה המלאה · export.mjs, שמירת התמונות והסרטונים
public/       תמונות וקבצים סטטיים
```

## כללים

- סודות (קוד המנחה, מפתחות) רק ב־`.dev.vars` או בסודות של Cloudflare וגיטהאב. אף פעם לא בקוד.
- לפני העלאה: `npm run typecheck` והבדיקה המלאה מקומית.
